📚 StudyTrack — Student Study Planner

StudyTrack is a simple and responsive study planner built using HTML, CSS, and JavaScript. It helps students organize their study tasks, track progress, and manage their daily learning goals.

✨ Features

- ➕ Add study tasks
- 📚 Organize tasks by subject
- 📅 Set due dates for tasks
- ✅ Mark tasks as completed
- 📊 Track study progress automatically
- 🗑️ Delete individual tasks
- 🔍 Filter tasks by completion status
- 💾 Save tasks in the browser using Local Storage
- 📱 Responsive design for mobile, tablet, and desktop

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Functionality and task management
- Local Storage — Saving tasks in the browser

🚀 How to Run

1. Download or clone this repository.
2. Open "index.html" in your web browser.
3. Add your study tasks and start tracking your progress.

No installation is required.
